# UX Flows

## UX principles

- Mobile first.
- Low cognitive load after a long school day.
- Maximum three primary Today cards.
- Daily logging normally under two minutes.
- Calm, actionable language.
- No guilt-oriented backlog.
- School and board preparation appear as one plan.
- `Why this?` is available for recommendations.

## 1. After-school daily flow

```text
Open app
 -> Dashboard
 -> optional Energy/available-time adjustment
 -> Today
 -> Start task
 -> Complete / Partial / Skip
 -> confidence after
 -> optional attempted/correct/errors
 -> next task
```

The student should not need to configure a schedule every day.

## 2. Study Now

```text
Tap Study Now
 -> choose 20/30/45/60/90 min
 -> one recommended task
 -> Why this?
 -> Start
 -> quick completion
```

## 3. School announces test

```text
Tests
 -> Add
 -> subject
 -> test type
 -> date
 -> chapters/topics
 -> max marks (optional before test)
 -> Save
 -> plan automatically recalculates
```

Target entry time: <30 seconds once curriculum exists.

## 4. After test

```text
Open assessment
 -> enter score
 -> optionally chapter/topic breakdown
 -> "Where were marks lost?"
 -> quick error classification
 -> Save
 -> readiness/revision/retest update
```

Detailed per-question entry is optional.

## 5. Revision

Revision screen groups:

- overdue
- due today
- upcoming
- mastered

If overdue volume is high, show a prioritized recovery plan rather than a large alarming count.

## 6. Weekly review

Show:

- focused preparation
- planned/completed
- revision completion
- readiness changes
- biggest improvement
- weak areas
- marks-lost categories
- next-week priorities

## 7. Plan setup/admin

Setup wizard:

1. board/class/academic year
2. curriculum version
3. subjects
4. plan start
5. target/hard completion
6. revision start
7. exam window
8. weekday/weekend capacity
9. school calendar defaults

Use templates only as defaults.

## 8. Parent dashboard - later

Show:

- ON TRACK / ATTENTION REQUIRED
- overall readiness
- subject risk
- syllabus trajectory
- revision consistency
- important upcoming events

Do not show detailed inactivity or minute-by-minute logs.

## 9. Visual design brief

Minimal, calm, high-contrast. Progress should communicate direction rather than reward compulsive checking. Avoid social/gamification patterns.
